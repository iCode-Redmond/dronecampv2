Windows setup

Open PowerShell, cd into the project folder, then paste this. The first line lets the virtual environment activate (Windows blocks it by default).

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process -Force

python -m venv venv
.\venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt

Then run a day's script, for example python day1\main.py
