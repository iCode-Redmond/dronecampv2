Functions, Boolean logic, and lists

A function receives values through parameters, performs a small job, and sends a result back with return. When a function reaches return, that function stops immediately. A missing return usually produces None.

BOOLEAN OPERATORSPython spells the operators as and, or, and not. A complete Boolean expression can be returned directly.
IF BLOCKSA colon begins the block. The statements underneath must be indented consistently. An early return can handle a special case.
LIST BASICSA list stores an ordered sequence. Use len(route) for its length, route[0] for its first value, and route.append(value) to add a value.
LIST LOOPSfor command in route: visits each value directly. Use range(len(route)) when the index number itself is needed.
def check_route(route): skipped = [] for command in route: if command == "forward": print("recognized") else: skipped.append(command) return skipped
